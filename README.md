# 🎤 Karaokey

> Like "karaoke" + "okay" — because you're always okay when you're singing.

Karaokey is a fun, lightweight, and free karaoke web app powered by YouTube and Supabase. No downloads, no sign-ups required — just search for a song and start singing!

---

## ✨ Features

- 🔍 **Search Songs** — Find your favorite OPM and international karaoke tracks instantly
- 🎵 **YouTube-Powered** — Streams karaoke videos directly from YouTube, no hosting needed
- 🗄️ **Supabase Backend** — Songs are stored and managed dynamically — no hardcoded links
- 📱 **Responsive** — Works on desktop and mobile browsers
- ⚡ **Fast & Lightweight** — Minimal UI, no clutter, just you and the mic
